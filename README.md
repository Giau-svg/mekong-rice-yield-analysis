
# Phân tích mối liên hệ giữa các yếu tố khí tượng và năng suất lúa tại Đồng bằng sông Cửu Long

## 1. Giới thiệu
Đồ án môn Phân tích dữ liệu, sử dụng Python để khám phá mối liên hệ giữa các yếu tố khí tượng và năng suất lúa tại Đồng bằng sông Cửu Long.

## 2. Mục tiêu
- Thu thập và chuẩn hóa dữ liệu khí tượng, nông nghiệp.
- Phân tích biến động năng suất và sản lượng lúa.
- Khám phá mối liên hệ giữa khí tượng và năng suất.
- Xây dựng và đánh giá mô hình hồi quy dự báo năng suất.
- Trực quan hóa kết quả và xem xét cảnh báo rủi ro năng suất thấp.

## 3. Nguồn dữ liệu dự kiến
- NASA POWER: dữ liệu khí tượng.
- Các nguồn thống kê nông nghiệp chính thức.

## 4. Công nghệ
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook
- Streamlit (giai đoạn dashboard)

## 5. Trạng thái
Đang khởi tạo dự án và khảo sát nguồn dữ liệu.
